# 用户侧安装：Claude Desktop 装完即可打新

面向**参与打新的用户**。装完之后不需要开任何终端，不需要跑任何服务。

---

## 用户机器上只有一个进程

之前的手册要开四个终端，那是**把开发环境当成了产品形态**。真实的职责划分是：

| 组件 | 谁运行 | 用户要管吗 |
|---|---|---|
| **MCP server** | 用户机器，Claude Desktop 自动拉起 | **这是唯一一个** |
| 元数据 API | 运营方托管 | 否 |
| 看板网站 | 运营方托管 | 否 |
| 结算 keeper | 运营方 / 社区 | 否 |
| 自动揭示守护 | **已内置进 MCP 进程** | 否 |

而且**投标能力不依赖运营方的服务**：API 挂掉时 MCP 自动回落到链上直读，
供应量、底价、窗口、阶段、已揭示需求全部照常，只有项目方撰写的文案会显示为不可用。

已实测：关掉全部本地服务，只跑 MCP，8 个工具全部可用。

---

## 安装：一个文件，双击

从 launchpad 网站下载 **`obscura.mcpb`**，然后任选一种：

- **双击**这个文件
- 把它**拖进 Claude Desktop 窗口**
- 或 Settings → Extensions → Advanced settings → Install Extension…

Claude Desktop 会弹出安装界面，让你填三项：

| 字段 | 说明 |
|---|---|
| **投标钱包私钥** | 输入时自动遮蔽，**由操作系统安全存储**，不落在任何文本文件里 |
| **单笔硬花费上限（ETH）** | 默认 0.05。签名前强制校验，对话里的任何内容都改不了它 |
| **RPC 端点** | 已预填公共节点；强烈建议换成你自己的 Alchemy/Infura |

**合约地址由运营方在打包时写死**，你不用输入——地址输错会把抵押金打进一个没人看管的合约。

装完即可用。**不用改 JSON、不用装 Node**（Claude Desktop 自带运行时）、不用开终端。

> **用专门的钱包。** 不要用主钱包，只放你愿意投入的金额。

### 校验完整性

页面上有 SHA-256。你下载的是一个会持有你私钥的程序，装之前先核对：

```powershell
Get-FileHash obscura.mcpb -Algorithm SHA256
```

## 使用：直接说人话

装好之后不用记命令，对 Claude 说就行：

> 帮我注册 obscura 参与者

> 现在有哪些 launch 可以参与？

> 分析一下 launch #3，值不值得参与

> 帮我投一个 150 枚、最高价 0.0002 ETH 的密封标

> 我有什么待办？

> 领取我的份额

### 注册与投标会动资金，agent 可能先跟你确认

这是正常的、也是应该的。工具描述里已经写明了约束边界：目标地址在启动时冻结、
函数在固定白名单内、金额与硬上限核对、且不存在任何通用转账工具。
把这些讲清楚之后，agent 通常就能判断该不该执行。

## 揭示：这是唯一会让你亏钱的地方

密封投标必须在揭示窗口内打开，否则**抵押金被没收**。这不是提示，是合约行为。

**自动揭示已经内置**，MCP 一启动就在跑，每 60 秒检查一次：

```
[obscura-mcp] auto-reveal active — checking every 60s while this process runs
```

### 但它有一个必须知道的边界

**它随 MCP 进程存活——也就是说，只在你的 Claude Desktop 开着的时候有效。**

如果你投完标就关掉 Claude Desktop，直到揭示窗口结束都没再打开，抵押金一样会没收。

三种应对，按可靠性排序：

1. **投标后让 Claude Desktop 保持开着**，直到看到揭示成功
2. 选择**揭示窗口较长**的拍卖（几小时以上），给自己留出反应时间
3. 需要硬保证的话，额外在一台常开的机器上跑独立守护：`npm run daemon`

关掉 `OBSCURA_AUTO_REVEAL=false` 可以禁用内置守护，但除非你自己另有安排，否则别关。

## 排错

| 现象 | 原因 |
|---|---|
| Claude 里看不到 obscura | 在 Settings → Extensions 里确认已安装且已启用。它**不会**出现在 Connectors 面板——那是账号级托管连接器的目录 |
| 安装时报配置无效 | 私钥必须是 `0x` 开头的 64 位十六进制；RPC 必须是完整 URL |
| `REFUSING TO SIGN` | 用了 Hardhat 公开测试密钥。生成一个新的 |
| 交易迟迟不确认 | 公共 RPC 限流，换自己的 endpoint |
| `NotRegistered()` | 先注册 |
| `WrongPhase()` | 窗口已过 |
| 元数据显示不可用 | 运营方 API 暂时不可达。**不影响投标**，链上数据照常 |
