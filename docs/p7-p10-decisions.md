## 1. 手续费四方分账（P7，FeeSplitter）

**文档已定**
- 比例口径：平台生态 20%、平台飞轮 20%、创建者 $c\in[0,40\%]$、国库 $60\%-c$；创建时写死，平台不可调。
- 以报价资产计；Pull 模式：各收款方自行 `claim`。
- 创建者份额在 FeeSplitter 中随时领取。

**需拍板**
| 项 | 推荐 |
|---|---|
| 平台生态收款地址 | Factory 部署时写死的多签地址（不可改） |
| 创建者收款地址 | 新增创建参数 `creatorRecipient`（文档草案有此字段），默认 = 创建者 |
| 国库份额 | 实时转入该币 Treasury（不经领取） |
| 飞轮份额 | 实时记到全平台 Flywheel 名下，按报价资产分别记账 |
| 现有 FeeSink | 被 FeeSplitter 取代；阶段 1 的 FeeSink 不再使用（结算零头也改进 FeeSplitter 的国库份额） |

## 2. 代币国库（P8，Treasury，每币一个）

**文档已定**
- 两种模式创建时锁定：`0 = 回购本币`（默认，回购后**销毁**）/ `1 = 按 24h TWAB 回馈持有人`。
- 不能向创建者或平台转账、不能改规则、不能动 LP。
- TWAB 合格集合排除：池子、合约地址、激励池地址；链下计算时 Distributor 公开数据与 Merkle 根，用户自行领取。
- `executeBuyback(maxQuoteIn, minTokensOut)` 任何人可调用。

**需拍板**（文档未写，但不写会被夹子吃掉）
| 项 | 推荐 |
|---|---|
| 回购防操纵 | 成交均价不得劣于池子 **30 分钟 TWAP × (1 + 2%)**；单次最多用国库余额的 **10%**；两次回购间隔 ≥ **1 小时** |
| 回馈模式的发放 | 每 24h 一期；国库把当期余额划入 Distributor 的该期额度，平台发布 Merkle 根；**根发布后 24h 异议期**才可领取（对应方案 D11） |
| 回馈资产 | 报价资产（文档：手续费以报价资产计，避免卖出本币） |
| 未领取的回馈 | 永久可领（不回收） |

## 3. 平台飞轮（P10，Flywheel，全平台一个）

**文档已定**
- 收全平台手续费 20%；回购市值前 10 名；排名用 **7 日时间加权市值** + **最低流动性门槛**；规则与去向公开。

**需拍板**
| 项 | 推荐 |
|---|---|
| 不同报价资产怎么排名 | **每种报价资产内单独排名、单独回购**（WETH 收入只回购 WETH 池的前 10）。跨资产排名需要价格预言机，且会把一种资产换成另一种 |
| 排名在哪算 | 链上：Flywheel 每 24h 对每个池记录一次 TWAP 检查点（任何人可触发），7 日 TWAP = 检查点差分；候选集合由链下提交、链上逐个校验 TWAP 与流动性门槛，并校验没有漏掉更高者（提交者附完整排序，合约验证单调） |
| 最低流动性门槛 | 池子报价资产储备 ≥ 该资产准入时设定的门槛（quoteAdmin 按资产设，新增字段） |
| 回购代币去向 | 文档"待定（销毁 / 协议金库 / 平台币持有人）"。推荐 **销毁**（没有平台币，进协议金库又多一个可动资金的特权） |
| 回购防操纵 | 同国库：TWAP 价格护栏 + 单次上限 + 冷却 |

## 4. 雷达激励（P9，Distributor）

**文档已定**
- 激励池 $xS$ 每日释放；释放口径二选一并写进合约：线性 $E_d = rS$，或递减 $E_d = rB_d$。
- 四个组成：LP 挖矿（份额×时长）、持仓 TWAB、交易返佣（单层、按自身手续费固定比例、有上限）、单层邀请（只奖励直接邀请人、按被邀请人手续费分成、有上限）。
- 不设任何多层级 / 团队业绩 / 按人数计酬。
- 链下计算，公开数据与 Merkle 根，用户自行领取。

**需拍板**
| 项 | 推荐 |
|---|---|
| 释放口径 | 创建参数，创建者二选一（默认线性） |
| 日释放率 $r$ | 创建参数，Factory 限制 0.1%–1%（默认 0.3%） |
| 四项权重 | 平台统一公布（例如 LP 40% / 持仓 30% / 返佣 20% / 邀请 10%），写进每期发布的计算数据；合约只保证"每期发放总额 ≤ 当期释放额" |
| 返佣比例与上限 | 例如 返自身手续费的 10%，单地址每日上限为当期释放额的 1% |
| 邀请关系 | **链上绑定**：被邀请人自己调用 `bindReferrer(addr)`，一次性、不可改、不能绑自己；每个邀请人奖励上限同上 |
| **LP 挖矿的前提** | 文档要求"提供额外流动性"，但现有池子按方案 D7 **不允许第三方加池**。要做 LP 挖矿就必须给 Pool 加第三方 `addLiquidity` / `removeLiquidity`（锁定 LP 仍永久不可动）。这会显著扩大池子的审计面 |
| 根发布者 | 平台多签；每期根发布后 24h 异议期 |

**文档已定**：冻结 → 允许但强提示（已有）；变余额（rebasing / 扣税 / 可增发）→ 拦截不上架；准入时指定价格来源。

**需拍板**
| 项 | 推荐 |
|---|---|
| 自动检测 | 新增 `scripts/check-quote-asset.ts`：在主网分叉上实测转账扣税与余额变化、扫描 mint/blacklist/pause/rebase 相关函数选择器、检查是否代理合约；输出报告，quoteAdmin 据此登记。合约层继续保留余额差校验 |

## 实现架构（据上述决定）

| 合约 | 数量 | 由谁创建 | 要点 |
|---|---|---|---|
| `PortusFeeSplitter` | 全平台 1 个 | Factory 构造时 | 每池登记四方比例；`onFee` 实时拆分：国库份额直接转给该币 Treasury，生态 / 飞轮 / 创建者份额记账，收款方 `claim` 自取 |
| `PortusTreasury` | 每币 1 个 | `createLaunch` | 模式 0 回购：`executeBuyback` 任何人可调，30 分钟 TWAP 护栏（均价 ≤ TWAP×1.02）、单次 ≤ 余额 10%、冷却 1 小时、买到即销毁；模式 1 回馈：每 24h `fundRewards` 把余额划入 Distributor |
| `PortusDistributor` | 全平台 1 个 | Factory 构造时 | 两类资金池：激励池（本币，按日释放，线性或递减）与国库回馈（报价资产）。`rootPublisher`（平台多签）发布每期 Merkle 根，总额受"已释放 / 已注资 − 已分配"约束，24h 后可领取；用户 `claim` 自取 |
| `PortusFlywheel` | 全平台 1 个 | Factory 构造时 | 每池每日 TWAP 检查点；每轮：任何人提名候选池，合约用 7 日 TWAP 市值 + 流动性门槛维护前 10；提名窗口结束后执行回购并销毁，单池单次 ≤ 报价储备 1%，均价 ≤ 短期 TWAP×1.05 |
| `PortusPool` | 每币 1 个 | `createLaunch` | 新增第三方加 / 撤池；手续费与 skim 多余报价资产都走 `FeeSplitter.onFee`；新增 `currentCumulativePrices()` 供 TWAP |
| `IncentiveVault` / `FeeSink` | — | — | 移除（职责并入 Distributor / FeeSplitter） |
