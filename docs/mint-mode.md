# 铸币挖矿模式（RADR 式发行）

> 2026-10-10 按用户提供的 RADR PAY「链上分配公式图谱」新增，与标准认购模式并存。
> 合约：`PortusMintToken`、`PortusTaxPool`、`PortusEmission`，入口 `PortusFactory.createMintLaunch`。
> **未经审计。**

## 用户决策

| 问题 | 决定 |
|---|---|
| 推荐算力里的“区” | **只算直推本人的持仓**（单层）。图中按整条伞下团队计算属于多层团队计酬，未采用 |
| 初始 LP 的 U 从哪来 | **定价认购募集**：与标准模式相同，募集款与代币在 `finalize` 时同笔注入池子 |
| 与标准模式的关系 | **并存**：创建页第一步选择“标准认购”或“铸币挖矿” |
| 参数 | **可调，默认值照图** |

## 机制

**首发**：创建时铸出首发量 S₀（默认 1000 万），一半给认购者，一半与募集款 R（默认 100 万 U）一起进池，开盘价 = 认购价 = R / (S₀/2)（默认 0.2）。认购、白名单、公开阶段、未达目标规则全部沿用 `PortusSale`。

**铸币节奏**（`PortusEmission`）：从认购结束时刻起，累计铸造量按阶段每 30 天复利增长，月内线性插值，封顶 `maxSupply`（默认 10 亿）。默认四阶段：6 个月 +10%/月、36 个月 +5%/月、36 个月 +3%/月、162 个月 +1%/月，约第 200 个月铸满。计划结束时若未铸满，之后不再增发。上限针对**累计铸造量**，销毁不腾出额度。任何人可调用 `mintDaily()`，把节奏允许的量铸进 `PortusDistributor`。认购退款（REFUNDED）时永不铸币。

**每日分配**（链下计算 + Merkle 根，`rewards/calc.ts · mintDayAllocation`）：

- 静态 `staticBps`（默认 50%）：24h 平均持仓（TWAB）≥ `MINT_MIN_HOLDING_TOKENS`（默认 1 枚）的地址从小到大排序，按竞争排名计权（并列同名次，下一名次跳过）。持仓越多排名越靠后、权重越大。
- 动态（其余）：对每个推荐人，每个直接被邀请人是一个“区”，区的值是该被邀请人的 24h 平均持仓。最大的一个区取立方根；其余区 ≤ 1 万枚按 ×10、超过 1 万枚按 10 万 + 超出部分。只有一层。
- 排除：池子、认购合约、Emission、分发合约、所有合约地址、四个税收地址。
- 根由 `rootPublisher` 发布，总额不超过已铸未分配额度，24h 异议期后可领；数据集写入 `REWARDS_DIR`。

**交易税**（`PortusTaxPool`，以代币收取，只在本池买卖时扣）：

- 买入 3%：销毁 1% + 社区 1% + 基金会 1%（按毛输出计）。
- 卖出 3%：销毁 1% + 社区 1% + 技术 1%（按卖出数量计）。
- 防暴跌：扣税后的卖出量 n 对池子的价格冲击 n / (T + n) 超过阈值（默认 3%）时，超出部分 × n 作为附加扣款，其中 `dumpBurnShareBps`（默认 50%）销毁，其余转入市值管理地址。
- 每边合计 ≤ 10%；阈值 1%–50% 或 0（关闭）。

**池子**：恒定乘积，无 LP 份额、无加池 / 撤池入口，开盘流动性永久留在池内；认购零头转入池子，`sync()` 并入储备。不进入平台飞轮（工厂用 `isMintPool` 与 `isPool` 区分）。

## 与图的差异和解释

| 图 | 实现 |
|---|---|
| 推荐算力按“区”（团队）计算 | 只算直推本人持仓（用户决策） |
| “倒序跳跃排名加权” | 解释为按持仓升序的竞争排名（1、2、2、4…） |
| “每月增长” | 解释为累计铸造量月复利，30 天一个月，月内按天线性释放 |
| 买入 1% 基金会 / 卖出 1% 技术 | 两个独立地址，创建时写死 |
| “50% 市值管理” | 转入创建时写死的市值管理地址 |
| 首期 500 万矿工 | 即定价认购卖出的那一半 |

## 已知风险

- **女巫攻击**：持仓排名按地址计权，把同一笔持仓拆到多个地址会提高总权重；最低持仓门槛只能部分缓解。动态部分同理，可以用多个小号互相邀请。
- **信任**：分配由 `rootPublisher` 在链下计算，链上只约束总额与异议期；每期数据必须公开以便复算。
- **平台收入**：此模式的交易税全部给项目方指定地址与销毁，平台（生态 / 飞轮）没有分成。
- **合规**：每日铸币按邀请关系分配，即使只有一层，在部分司法辖区仍可能被认定为拉人头式激励，上线前需要法律意见。
- 绕过：任何人都能在其他 DEX 为同一代币建池，绕开本池的交易税。
